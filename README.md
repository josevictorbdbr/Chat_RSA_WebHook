# Chat Criptografado com RSA e SHA-256

Projeto que usa duas aplicações que conversam entre si usando criptografia assimétrica RSA

## Como rodar:
- Abra dois terminais(Recomendado a função do VSCode de deixar um terminal ao lado do outro)
- Em um deles digite `python cliente_a.py`
- No outro digite `python cliente_b.py`
- Após ambos estarem rodando, é possivel mandar mensagem de um para outro
